# 局域网连接安全配置

CapsWriter-Offline 默认使用 `local` 模式，服务端只监听 `127.0.0.1`，仅供同一台电脑上的客户端连接。不要仅通过把 `addr` 改成 `0.0.0.0` 来开放服务。

## 局域网模式

先生成一个随机令牌，长度不得少于 32 个字符：

```powershell
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

在服务端启动进程的环境中设置令牌，并修改 `config_server.py`：

```powershell
$env:CAPSWRITER_AUTH_TOKEN = '刚才生成的随机令牌'
```

```python
network_mode = 'lan'
addr = '0.0.0.0'
```

在每台客户端启动进程的环境中设置同一个令牌，并将 `config_client.py` 的 `addr` 改为服务端的局域网 IP。令牌不应写入仓库、日志、快捷方式参数或聊天记录。环境变量变更后需要重启对应进程；轮换时应同时更新服务端和所有客户端。

LAN 模式缺少令牌或令牌过短时，服务端会在加载模型前拒绝启动。无令牌或令牌错误的连接会在 WebSocket 握手阶段收到 HTTP 401。

## TLS

普通 `ws://` 会以明文发送令牌和音频，只适合可信局域网。跨不可信网络时，应使用可信反向代理终止 TLS，或在服务端同时配置：

```python
tls_certfile = '证书文件路径'
tls_keyfile = '私钥文件路径'
```

客户端同时配置：

```python
use_tls = True
tls_ca_file = ''  # 公共 CA 签发的证书留空；自签名证书填写受信 CA/证书路径
```

客户端会改用 `wss://` 并执行证书链与主机名校验。不要通过关闭证书校验来绕过配置错误。

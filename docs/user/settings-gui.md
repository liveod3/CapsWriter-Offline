# 使用桌面客户端

客户端现在以主窗口启动：**概览**显示听写、识别连接、文本处理和录音快捷键，左侧可进入 **识别历史**、常用设置和 **高级设置**。客户端打开后自动连接配置中的识别服务；服务端仍独立启动和管理。首次使用本次源码改动时，更新客户端依赖并退出旧客户端，再启动新版，避免两套录音快捷键同时运行。

源码环境推荐运行以下命令，脚本会寻找已注册的 `capswriter` 环境并启动无终端的客户端：

```powershell
./start.ps1 -Client Gui
```

也可在已激活环境运行 `pythonw start_desktop.pyw`；直接双击该文件需要 `.pyw` 关联到同一环境。GUI 和终端客户端使用不同入口：`python start_client.py` 继续启动终端客户端。包含本次改动的发行包使用 `CapsWriter.exe` 打开 GUI，`start_client.exe` 保留终端行为。旧发行包仍以原入口为准。

## 启动、托盘与退出

- 默认显示主窗口，无需再点击“启动听写”。服务未连接时显示检查地址、端口和服务运行状态的提示，并自动重试。
- 连接并准备好麦克风后显示 **等待触发键**，按下快捷键才开始听写；录音与后续处理各有独立提示。当前实现会提前打开麦克风，因此 Windows 可能显示“麦克风正在使用”；待命时的音频会被丢弃，不会作为听写任务保存或上传。
- 托盘、窗口和概览使用原来的麦克风图标；录音时显示红点，停止录音后移除。悬停托盘可查看当前状态。
- 在 **通用与听写 → 语言与界面** 启用 **启动时直接进入托盘**，保存后下次启动只显示托盘图标。托盘不可用或已关闭时仍显示主窗口。
- 关闭主窗口会隐藏到托盘，听写继续运行，窗口中的未保存草稿也保留。点击托盘图标或再次打开同一安装目录的桌面入口即可唤回主窗口。
- **退出客户端** 会先弹出确认对话框，默认选择取消；正在录音或处理时会说明中断风险。确认后先保存有效的客户端设置，再结束客户端任务并释放麦克风，服务端继续运行。保存失败时不会继续退出；无效修改或未保存的预设草稿需另行确认放弃。托盘关闭或不可用时，窗口关闭按钮执行退出流程。
- 启动失败时主窗口显示错误和重试按钮；配置仍可编辑。失败状态持续期间不会反复弹出窗口抢占焦点。

启动脚本已统一为 `start.ps1`，替代原来的 `start_capswriter.ps1` 和 `start_desktop.ps1`。必须明确选择启动目标；不带参数或使用 `-Help` 时只显示帮助，不启动任何程序。

| 命令 | 启动内容 |
| --- | --- |
| `.\start.ps1 -Client Gui` | 仅 GUI 客户端 |
| `.\start.ps1 -Client Console` | 仅终端客户端 |
| `.\start.ps1 -Server` | 仅服务端终端 |
| `.\start.ps1 -Server -Client Gui` | 服务端终端和 GUI 客户端 |
| `.\start.ps1 -Server -Client Console` | 服务端和客户端两个终端 |

在上述命令后添加 `-WhatIf` 可以预览，不会启动程序。脚本帮助跟随系统界面语言，不读取客户端配置。已有服务端运行时只选择客户端；组合启动不会自动检测已有服务端，也不会等待模型加载完成，客户端会按原配置自动连接和重试。不要同时启动终端客户端和 GUI 客户端。

也可以只打开文件编辑窗口，不启动麦克风或模型：

```powershell
conda run -n capswriter python start_client.py settings gui
```

独立文件编辑模式会明确显示“运行状态未知”；桌面客户端内的设置能查看所拥有客户端的生效状态。带终端客户端的旧托盘设置入口仍受支持。编辑或浏览设置不会自动发送模型测试请求、读取光标上下文或查询剪贴板。

## 选择识别语言和麦克风

在 **通用与听写 → 麦克风与采集** 中直接选择识别语言，无需填写语言代码。“自动检测”由服务端模型判断；中文、英文、粤语等选项的实际支持范围取决于服务端加载的模型，选择语言不会安装或切换模型。

麦克风列表进入此页面时自动读取，普通列表优先使用 Windows WASAPI，显示麦克风名称，隐藏同一设备的其他驱动接口和底层引脚。**系统默认** 后面显示当前默认输入。连接、断开或默认输入变化时，Windows 音频通知会触发自动更新，不需要手动刷新。连续通知会合并；下拉菜单打开时延后更新，避免条目移动造成误选。离开设置或隐藏到托盘时暂停自动列表查询，回来后更新；通知不可用时采用低频自动查询，**刷新** 仍可用于立即重试。读取列表只查询设备信息，不启动录音或重启当前音频流。

如果希望插拔耳机时跟随 Windows 的默认输入切换，请选择 **跟随系统默认**；选择具体麦克风则固定使用该设备。GUI 列表更新与录音端已有的设备监测、恢复逻辑分别运行，不会因为刷新列表而切断正在进行的录音。

设备查询在后台完成，不显示短暂的“正在搜索”文字，也不会改变选项行的位置。查询失败或设备不可用时，麦克风旁会出现小型状态图标，悬停或点击可查看详情；恢复后图标消失，其占位保持不变。通用与听写的两组选项用淡细分隔线区分各行。

选择后设置自动保存。**更换麦克风需要完整退出并重新打开客户端才生效**，页面会显示重启提示。设备断开或读取失败时，原选择仍保留并显示说明，不会擅自换用其他麦克风。已有配置中的自定义语言、设备名称或编号也会保留；设备与接口完全重名的条目不可新选，可先在系统中为设备设置不同名称。

## 调整提示词

1. 打开 **文本与提示词**，选择自动预设。选择“仅显式触发词”后，不会自动选择一个默认预设。
2. 设置数字、标点、语气词、英文还原和转写错误修正开关，选择最小、自然或流畅强度。
3. 在预设编辑器中选择要检查的预设，点击下方 **预览最终提示词**。预览包含当前窗口尚未保存的客户端选项和该预设草稿，不会调用模型。
4. 模块和强度在编辑结束后自动保存，无需点击保存按钮。预设中的模型引用、触发词、自定义提示词等，使用编辑器内的 **保存此条目** 单独保存。

模块只影响“基础提示词 + 纠错模块”类型的预设。完整自定义提示词继续保留原有行为。改为组合模式并保存会移除该预设的完整自定义提示词；切换前请保留需要的内容。上下文仍需客户端与预设两个开关同时允许。服务端数字格式化、客户端末尾标点移除是独立处理，见[提示词契约](../reference/correction-prompts.md)。

## 配置模型和服务

在 **模型与服务** 中选择或新建服务商，填写 API 类型、地址、模型、超时和密钥环境变量名，再保存该条目。环境变量密钥优先于文件密钥。密码框不显示已有密钥；留空保留已有密钥，输入新值替换，勾选明确清除才会删除原值。打开窗口不会创建 `providers.toml`，第一次保存服务商时才会创建。

预设通过稳定 ID 引用服务商。新 ID 使用英文字母、数字、下划线或连字符；已有 ID 不能在窗口中直接改名。删除被预设引用的服务商，或删除仍被选作自动默认值的预设，会显示验证错误。先保存新的引用或默认值，再删除旧条目。

客户端 ASR 地址、端口、TLS 设置在页面上方，校验通过后自动保存，退出并重新打开客户端以使用新连接配置。服务端模型选择、模型路径、复杂快捷键、应用专用输出规则以及费用费率仍使用高级文件配置；客户端文件入口移到 **设置 → 高级设置 → 高级配置文件…**，不再出现在普通设置页底部；原托盘文件入口保留。

## 理解保存状态

客户端选项停止编辑约 0.6 秒后自动校验并保存；数值输入在完成编辑后提交。端口范围、分段时长与重叠关系、目录等无效输入会在页面说明，整批修改在修正前不写入文件。保存失败保留草稿，可重试；保存过程中继续修改的内容也会随后保存。

配置项名称旁的圆圈 **?** 提供用途、影响和取值说明，鼠标悬停即可查看，也可点击，或用 Tab 聚焦后按空格或 F1 打开，按 Esc 收起。详细说明不再常驻在每个选项下方；输入错误和需重启状态仍直接显示。短值使用紧凑输入框，宽窗口并排显示设置组，窄窗口恢复单列。预设和服务商仍单独保存条目，说明放在各自编辑器内。

| 状态 | 含义 |
| --- | --- |
| 未保存 | 当前窗口中有草稿修改 |
| 已保存 | 已写入文件；独立模式无法判断其他进程是否生效 |
| 待任务结束 | 已保存，等待当前听写或文件任务结束后热加载 |
| 需重启 | 已保存，资源设置需重启客户端 |
| 已生效 | 与所连接客户端的当前运行值一致 |

连接客户端时，悬停字段可查看运行值。桌面客户端空闲时约每 200 毫秒刷新录音等状态，每两秒检查配置变化；后台刷新和客户端设置自动保存均保持控件可用，不会反复变灰。页面恢复较小的原有字号。滚轮经过数值框或收起的下拉框时只滚动页面，不改变设置。数值可直接输入或用键盘方向键调整，下拉列表展开后仍可滚动选择。

文件在外部被修改时，没有草稿的表单会自动显示新设置，无需手动重载。有未保存修改时会保留草稿，并拒绝覆盖外部修改；只有此时才显示 **使用文件中的设置…**，确认放弃草稿后可查看更新后的设置。普通设置页底部显示自动保存状态；保存失败时出现重试按钮，高级文件入口位于独立的 **高级设置** 页面。错误不会自动修复或强行覆盖文件。

服务商和预设保存后用于后续 LLM 请求，正在进行的请求保留原快照。界面语言修改后需退出并重新启动桌面客户端才能更新窗口文字；听写提示按原有安全边界切换语言。关闭窗口隐藏到托盘不等于重新启动。

## 查询识别历史

点击左侧 **识别历史**，首次进入会查询本月截至今天的记录。选择 **今天 / 最近 7 天 / 本月 / 不限日期** 后立即更新结果；点击日历修改自定义日期，或输入关键词后，停止编辑约 0.3 秒便会自动筛选。日期与关键词可以单独使用，也可以组合。按回车或点击 **刷新** 可立即重新读取当前条件下的记录，**清除条件** 会查询不限日期的全部已保存记录。

结果按日期和时间从新到旧显示，每页最多 30 条；顶部显示当前查询范围、结果总数和页码。通过 **上一页 / 下一页** 翻页，也可在 **页码** 框输入目标页，按回车或点击 **跳转**。更改筛选条件会回到第一页，页码范围跟随查询结果更新。

读取期间保留当前结果与详情，只在提示区域显示进度，不会将整页按钮反复变灰。快速连续切换条件或记录时，以最后一次选择为准。刷新后仍在结果中的已选记录会保留；未选记录时，详情区域中央显示淡色提示。后台状态轮询不会自动查询历史。

选择记录后，右侧提供三个视图：

- **处理过程**：按初始识别、交给 LLM 的文字、LLM 输出、最终结果展示；下方列出模型、耗时、Token 用量与费用。顶部直接显示金额和费用来源。
- **请求信息**：查看当时保存的预设、请求 ID、实际系统提示词和光标参考文本。
- **原始记录**：核对原始 Markdown 文本，可点击 **复制记录**。**复制结果** 只复制最终文字，**打开当日文件** 使用记事本打开对应文件。

关键词匹配整条已保存记录。缺失的原文、LLM 信息和费用会明确说明，不能用当前设置补推过去的请求。原文与结果相同时旧格式不单独保存原文，因此也可能显示“未单独保存”。费用通过已保存的请求 ID 关联本地用量账本，区分服务商返回金额、估算金额与未知；未知不代表免费。窗口不会执行记录中的链接或 HTML，不会查询服务商、读取剪贴板或补录未保存的内容。

历史来自当前生效的 `transcript_dir`，默认是 `records/transcripts`；独立文件编辑模式使用已保存的目录配置。关闭历史保存后，已有记录仍可查询。没有保存过的听写无法恢复，历史中的完成状态也不代表文字一定成功插入目标应用。

为避免大记录拖慢客户端，单次查询最多读取 16 MiB、每天最多读取末尾 2 MiB，并检查最多 10,000 条记录，目录检索也有数量上限。达到范围限制时请缩小日期范围；无法读取的文件会有提示，结果数量仅代表已检查范围。单条详情最多显示 64,000 个字符，超出时可打开当日文件查看全文。查询后文件发生变化时会提示重新查询。旧格式没有时间标题的日文件会作为一条“当日记录”显示。

## 查看记录与诊断

**输出与记录** 分开控制文本历史、原文、LLM 记录、上下文和录音。**状态与诊断** 展示连接、录音和暂停状态，也可主动暂停/恢复或重连麦克风。独立文件模式不能执行这些运行操作。

点击 **读取最近诊断** 查看最近文件尾部的最多 80 条元数据，包括请求 ID、HTTP 状态、失败类别、阶段耗时等实际已记录字段；不展示文本和上下文副本。更久的记录及已授权保存的正文仍从[诊断文件](logs-and-records.md)读取。输入 `YYYY-MM` 可查询本地[费用汇总](llm-costs.md)，不会向服务商询价。不同币种和不同可信度的金额保持分开。

自动键盘、窗口生命周期和缩放渲染检查已经覆盖；真实双屏混合 DPI、焦点恢复和屏幕阅读器检查仍待验收，详见[验证记录](../validation/P1-settings-gui.md)。

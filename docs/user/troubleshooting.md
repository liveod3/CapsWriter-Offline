# 排查常见故障

先确认服务端、客户端及实际配置，再按症状检查。诊断材料只保留必要的错误类别、版本、时间和任务 ID；分享前去除私人内容。

## 快捷键或文字输入没有反应

1. 确认服务端模型已就绪，客户端正在运行且没有手动暂停。
2. 查看客户端启动提示中的实际快捷键；模板为右 Ctrl 和鼠标 X2 切换录音。
3. 将光标放入普通文本编辑器进行对照。
4. 若只在管理员程序中失败，核对客户端与目标程序的权限级别。

部分应用不兼容模拟 Unicode 输入，可在 `paste_apps` 中选择粘贴输出。字段说明见[客户端模板](../../config_templates/config_client_template.py)。

## 无法打开麦克风或开头缺字

检查 Windows 麦克风隐私设置是否允许桌面应用访问，确认默认输入设备可用，再从托盘重连麦克风。设备被独占时，检查设备属性与其他录音应用。

模板在闲置 20 秒后释放麦克风。恢复设备需要时间，应等待就绪提示再说话。`enable_idle_suspend` 和 `idle_suspend_seconds` 控制此行为，修改后需重启。手动暂停必须从菜单恢复。

## 静音或讲话时出现无关文字

模型可能对底噪或静音输出不存在的内容。若正常讲话也持续出错，先区分输入音频异常和模型解码异常，再比较后端与重启前后的结果。

项目保留了一份[间歇性 Qwen ASR 报告](../archive/QWEN-ASR-2026-08-09.md)，目前仍待复现和定因。它没有证明蓝牙、GPU 或某次重连就是根因。排查时如需保存音频，应由你明确开启并在本机试听，不要自动上传录音。

## 模型或 DLL 加载失败

核对 `model_type`、`ModelPaths`、目录层级、VC++ 运行库和实际后端。模型需要手动下载。更新程序不意味着必须重新下载未变化的模型。

若仅 GPU 失败，按[GPU 排查步骤](gpu.md)用同一输入对比 CPU；不要直接替换成不匹配 ABI 的 DLL。对齐超时或异常导致服务停止时，检查原因后重启服务端。

## LLM 报错或没有应用设置

密钥缺失时，从托盘打开本机 Provider TOML。检查 `api_key_env` 是否覆盖文件密钥，确认实际 `base_url` 与模型。不要把真实密钥填入模板。

配置重载被拒绝时，修正完整文件后再保存；程序继续使用最后有效配置。显示等待任务边界时，先结束当前工作。显示需要重启时，对应资源仍使用启动值。参阅[配置与记录](configuration.md)。

## 查找记录与日志

保存位置见[记录表](configuration.md#区分保存内容)。最新诊断入口为 `logs/client_latest.log` 和 `logs/server_latest.log`；文件转录完成汇总还会显示本次任务日志位置。

旧录音仍在原来的年份目录；托盘打开的是当前新录音目录。更改 `audio_dir` 不会搬移旧文件。

## 隐藏控制台或开机启动

托盘可显示或隐藏控制台。需要开机启动时，用 Win+R 打开 `shell:startup`，加入服务端与客户端快捷方式，并核对工作目录。启动后仍需等待服务端模型就绪。

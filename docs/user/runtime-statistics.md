# 查看听写耗时与运行记录

运行统计保存麦克风唤醒、听写转写等待、LLM 准备与请求、文字输出和停止后的总体等待。
它只保存任务标识、耗时、结果与必要的模型元数据，不保存识别正文、提示词、上下文或音频。

## 开启与查看

在设置的**诊断**页面开启**保存运行统计**，重启客户端后生效。默认开启。
它独立于诊断日志等级、诊断文件开关、正文保存和 LLM 费用开关。

**统计 / Statistics** 页面支持**今天、本周、本月、本年、近 7 天、近 30 天**，均按本地日历日并包含今天。
本周从周一开始，本月从每月 1 日开始，本年从 1 月 1 日开始；它们与滚动的近 7 天、近 30 天分别保留。
概览中的运行任务、保存文字、Token、费用和耗时共用这一范围。悬停日期说明可查看带时区的精确边界。
任务按开始时间归入范围，费用按请求开始时间归入范围，保存文字按归档日期归入范围；跨午夜时各项数量可能不同。

顶部四张概览卡片显示听写任务数、保存文字条数、Token 和费用，名称使用与耗时卡片一致的醒目标题。
下方两张宽卡片分别展示停止后总体等待和麦克风唤醒，不再添加额外标题。
每张卡片上方用浅紫底、大字突出最近一次，失败、跳过等状态有独立标签，正常完成时不显示标签。
任务开始时间另起一行。
中位数、平均值、最大值、P95 分别放在四个独立格子中，标签和深色数值分行显示；单位统一为毫秒。
样本数放在底部；样本不足时 P95 带 `*`，悬停 P95 名称可查看说明。
窄窗口下两张耗时卡片自动上下排列。
最近记录附带任务开始时间与结果，失败或不适用时会如实标明，不会拿更早一次成功的数字代替。
关闭正文保存后，任务数仍可独立记录；保存文字条数不等于实际使用次数。

页面已移除听写耗时、LLM 与费用、任务详情三个表格分页，以及数据健康区块。
详细阶段记录仍保存在数据库中，移除界面区块不会停止采集或删除历史记录。
字段说明统一放在名称上：悬停概览卡片标题或四项统计名称，可查看简短定义。
数值上的悬停信息补充该次任务的时间与结果。

不足 20 个样本的 P95 带有 `*`，此时尾部延迟尚不稳定。失败和取消的阶段不计入成功耗时分布，
但同一任务中此前已成功完成的阶段仍可计入。不同指标版本不会混合统计。
平均值为同一批有效阶段样本的算术平均，最大值也是这批样本中的最大耗时；原文回退后正常完成的输出仍计入输出耗时。
“最近一次”独立展示实际结果，因此失败请求的最近耗时可能大于成功样本的最大值。
最近的任务还没产生某项测量时，该指标保留最近已有的记录及其时间，不会伪造当前任务的完成值。
麦克风已经处于就绪状态时，“唤醒”显示为不适用，不会作为零毫秒冷启动影响平均趋势。

记录中的 **not applicable（不适用）** 表示该次任务不需要执行这个阶段，例如麦克风已经就绪，
或者没有启用 LLM 处理。这不是错误，也不是零毫秒，不计入耗时平均值。
不适用测量数统计的是阶段记录数量，不是听写任务数量；一次任务可能有多个不适用阶段。

运行查询最多加载 10,000 个任务和 200,000 项测量，每项指标最多展示 32 个分组，
单次任务详情最多展示 128 项测量。达到读取上限会显示部分结果提示，不能将这些数量当作全时段总计。
这不会删除或停止保存数据库中的其他记录。费用每月最多读取 10,000 条、每次查询最多读取 30,000 条，
全年视图触及上限时同样提示部分结果，不将已读取的子集标为全年总计。正文读取也有上限，并会提示。

**最近说过的话**位于 **概览** 页的录音快捷键面板下方，固定完整展开最新 5 条；单击复制完整最终文字，窗口中间偏下会短暂显示“内容已复制至剪贴板”的 GUI 提示。
页面仅在可见时刷新，不会启动麦克风或向服务商发送请求。

“停止后总体等待”从程序接受停止指令开始，到文字插入操作返回为止。
它包含停止之后仍需完成的上传、转写、处理与输出等待；不包含之前说话的时间。
自动回车延迟和 UDP 发送另记。插入操作返回不代表程序读取并验证了目标应用的文字。

## 保存位置与旧账本

运行统计和费用记录共用 `activity.sqlite3`，默认位于 `llm-costs`。
如果已在 `LLM/costs.toml` 的 `tracking.directory` 设置了目录，会沿用该目录。
客户端运行期间修改数据库目录需要重启，费用开关和费率仍遵守原有设置行为。

旧的月度费用账本继续可读，新记录只写入统一数据库。查询会合并并按请求 ID 去重。
旧文件不会被自动搬动、删除或改写。需要将旧数据导入统一库时，可在项目环境执行：

```powershell
python scripts/activity_records.py --directory llm-costs --import-legacy
```

应先退出旧版本客户端，避免它继续修改旧账本。使用自定义目录时替换 `llm-costs`。
导入按月提交，可以重复执行；发现同一 ID 对应不同记录时会停止该月导入，保留源文件。

查看某次听写的完整元数据：

```powershell
python scripts/activity_records.py --directory llm-costs --task <完整任务ID>
```

费用查询仍可使用原有 `scripts/llm_costs.py`。
关闭费用记录不会关闭运行耗时统计；关闭运行统计也不会关闭费用记录。

## 完整性与保留

数据库不受诊断日志的过期清理影响，目前不自动删除历史统计。
如写入失败、队列溢出或异常退出，页面会保留未知、未完成或部分结果的含义，不将它们当作零。
磁盘持续不可写时只能通过诊断或界面报告错误，无法保证数据库本身记录下这个故障。

目前没有采集服务端 ASR 排队／纯推理耗时，也没有文件转写统计。
麦克风唤醒终点是新音频流第一次交付音频块，不代表检测到了人声。

完整字段、计时边界与兼容规则见[数据库设计规范](../reference/activity-database.md)。

## Preserve behavior distinctions

The client parses arguments before importing hardware/UI. No arguments select `mic`; `transcribe` handles media and directory inputs; `rebuild-srt` needs a TXT/JSON pair and performs no ASR.

The WebSocket subprotocol name `binary` still carries JSON with Base64-encoded, 16 kHz, mono float32 audio. The receiver uses the client's segmentation settings. Worker sessions and scheduler buffers use `(socket_id, task_id)` keys.

ASR and punctuation run in the recognition process. `ProcessAlignerProxy` routes file alignment to a sibling process when the engine lacks timestamps. Idle alignment cleanup exits that process; abnormal exit/timeouts follow bounded service shutdown. Text merging and timestamp merging are separate paths.

LLM configuration is static TOML loaded per request. There is at most one automatic preset, explicit triggers override it, and actions have no conversation history. `llm_enabled=False` prevents provider requests but does not disable remote ASR, UDP, or independently enabled ASR caret reference.

Read only relevant, necessary diagnostic excerpts. Latest logs, monthly diagnostics, per-run transcription logs, transcripts, and audio have separate roles. Logs alone do not establish a cause; compare code, effective settings, and a reproducible case.

# 常见问题

## 快捷键或上屏没有反应

先确认服务端与客户端都在运行，客户端未暂停。当前模板使用右 Ctrl 或鼠标 X2 切换录音；已有安装应检查本机 `config_client.py`，不要按旧说明默认使用 CapsLock 长按。

目标程序若以管理员权限运行，客户端通常也需要相应权限。部分编辑器或输入法不兼容 Unicode 模拟输入，可在 `paste_apps` 中配置粘贴输出，字段见[客户端模板](../config_templates/config_client_template.py)。

## 没有说话，为什么仍识别出文字

静音或底噪也可能让模型输出不存在的内容。只在需要输入时开始录音，避免把无效音频送入识别。若实际讲话也持续出现无关内容，需分别检查采集音频与模型；不能仅凭结果认定是麦克风或模型故障。

## 无法打开麦克风，或漏掉开头

检查 Windows 麦克风隐私设置，允许桌面应用访问麦克风；确认默认输入设备可用，再尝试托盘的 Reconnect microphone。设备被其他软件占用时，可检查设备属性中的独占模式。

当前模板启用闲置挂起，空闲 20 秒后释放麦克风；再次录音需要恢复设备，不能保证始终零启动延迟。相关配置为 `enable_idle_suspend` 和 `idle_suspend_seconds`。手动暂停需要先恢复，录音快捷键不会解除手动暂停。

## 录音和处理过程有没有屏幕提示

有。当前客户端提供录音、转写及 LLM 等待状态提示，完成、取消或失败后清理。详见[文本动作与记录](文本动作与记录.md)。旧文档中“不做 GUI 提示”的说明已不适用。

## 记录保存在哪里，是否自动清理

- 听写文字：默认开启，位于 `logs/transcripts/YYYY/MM/DD.md`。
- 音频：默认关闭；开启 `save_audio` 后保存到 `YYYY/MM/assets/`，使用 MP3 或降级 WAV。
- LLM 动作输入/输出：默认关闭，位于 `logs/text-actions/YYYY/MM/DD.md`。
- 诊断日志：有 `logs/client_latest.log`、`logs/server_latest.log` 和 `logs/diagnostics/YYYY/MM/`；单次文件转录日志在 `logs/transcribe/YYYY/MM/`。

诊断归档默认保留 30 天，在初始化或跨日写入时清理；这一策略不清理文字、音频和 LLM 动作记录。详细开关见[记录说明](文本动作与记录.md#文字记录与音频独立保存)。旧模块的诊断日志仍可能包含识别文本，分享排障材料前应检查并脱敏。

录音默认不保存，排查采集问题时需要临时开启保存；已有音频不要随意上传。

## 模型会自动下载吗

当前需要手动下载并放置模型，见[模型说明](模型下载的若干问题.md)。软件与模型分开分发，更新软件不必重复下载未变化的模型。

## 如何隐藏控制台或开机启动

通过托盘的 Show/Hide console 切换控制台。需要开机启动时，用 `Win+R` 打开 `shell:startup`，放入服务端、客户端的快捷方式，并检查快捷方式的工作目录。
